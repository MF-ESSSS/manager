# Steam Manager

Сайт для управления аккаунтами Steam: логин/пароль, maFile (коды Steam Guard),
прокси на аккаунт, и кнопка «Обновить» (реальный вход в Steam — статус, уровень,
баланс, аватар).

## Деплой на Render (бесплатно, проще всего)

1. Зайдите на render.com, зарегистрируйтесь (можно через GitHub).
2. Залейте эту папку к себе на GitHub в новый репозиторий (через сайт GitHub:
   "Add file -> Upload files", перетащите все файлы из этой папки).
3. В Render: New -> Web Service -> подключите этот репозиторий.
4. Build Command: `npm install`
5. Start Command: `node server.js`
6. Instance Type: Free.
7. Нажмите Create Web Service — через пару минут Render даст вам ссылку вида
   `https://ваш-сервис.onrender.com`. Откройте её — это и есть сайт.

Бесплатный план Render «засыпает» без запросов ~15 минут и первый запрос после
сна грузится дольше (пока сервер «просыпается»).

## Деплой на Railway (тоже бесплатно, лимит по часам/деньгам в месяц)

1. Зайдите на railway.app, войдите через GitHub.
2. New Project -> Deploy from GitHub repo -> выберите репозиторий с этой папкой.
3. Railway сам определит Node.js и Procfile, ничего настраивать не нужно.
4. В Settings -> Networking нажмите "Generate Domain" — получите ссылку
   вида `https://ваш-проект.up.railway.app`.

## Деплой на свой VPS

1. Установите Node.js 18+.
2. Скопируйте эту папку на сервер, выполните `npm install`.
3. Запускайте через pm2 или systemd, чтобы сервер поднимался сам после
   перезагрузки, например: `npx pm2 start server.js --name steam-manager`.
4. Откройте порт (по умолчанию 3000) в фаерволе, либо поставьте nginx
   как reverse proxy с доменом и HTTPS (рекомендуется, т.к. иначе пароли
   идут по http).

## Важно про безопасность

- Сайт хранит пароли и maFile в localStorage браузера без шифрования.
  Открывайте сайт только в своём браузере и не используйте чужие хостинги,
  если туда ходят ещё люди.
- Используйте HTTPS (Render и Railway дают его из коробки; на своём VPS —
  через nginx + certbot), иначе логин/пароль видно по дороге до сервера.
- Поддерживаются только http/https-прокси для функции «Обновить»
  (socks5 пока не реализован на сервере).
- Steam банит за частые попытки входа. Не жмите «Обновить» слишком часто
  на одном аккаунте.
